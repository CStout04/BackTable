# Sprinter

*A fast-paced ETSU-themed browser game inspired by the Chrome Dinosaur*

## Overview

**Sprinter** is a lightweight, single-player browser game inspired by the classic Chrome Dino game, redesigned with an ETSU theme.

## Gameplay

* Press **↑ (Up Arrow)** or **Tap** to jump
* Press **↓ (Down Arrow)** or **Swipe Down** to duck
* Avoid obstacles to keep running
* The game speeds up over time

**Goal:** Survive as long as possible and achieve the highest score.

## Tech Stack

* **JavaScript** (core game logic)
* **HTML5 Canvas** (rendering)
* **CSS** (styling and responsiveness)
